# Конструктор опросников (Quiz Helper)

Универсальный волонтёрский сайт-помощник: короткий пошаговый опрос → итоговая
инструкция (Markdown). Подходит для любых задач, где нужен опросник с выдачей
результата: первая помощь, подбор услуги, диагностика, чек-листы и т.п.

Пользователь отвечает на вопросы, дерево вопросов ведёт его к нужной инструкции,
которую можно прочитать и скопировать.

## Технологии
- Python 3.13 + FastAPI (uvicorn)
- Jinja2-шаблоны, инструкции в Markdown
- Чистый CSS, тёмная/светлая тема (подхватывает системную тему браузера)

## Структура
- `app/` — FastAPI-приложение (`main`, `loader`, `quiz_engine`, `renderer`) + шаблоны и статика
- `data/` — настройки (`settings.yaml`), дерево вопросов (`questions.json`), статьи (`articles/*.md`), описание проекта (`about.md`)
- `requirements.txt` — зависимости Python

## Как сделать свой опросник (без программирования)

Скачайте репозиторий и отредактируйте только содержимое папки `data/` и логотип.
Пересборка не нужна — файлы смонтированы в контейнер и подхватываются сразу.

### 1. `data/settings.yaml` — название, логотип, контакты, заголовки
```yaml
site_name: "Мой опросник"          # название в шапке и вкладке браузера
logo: "img/logo.png"               # путь к логотипу относительно static/ (без слэша в начале)
instruction_title: "Инструкция"    # заголовок карточки итоговой инструкции (та самая «переменная заголовка»)
footer: |                          # текст подвала (можно много строк)
  Короткое описание проекта.
contacts:                          # контакты (необязательно)
  Телеграм: "https://t.me/example"
  Почта: "info@example.org"
article_titles:                    # заголовки под каждую инструкцию (необязательно)
  result_a: "Что делать в случае А"
  result_b: "Что делать в случае Б"
about_text: |                      # текст страницы «О проекте» (необязательно)
  Описание вашего проекта.
```

### 2. Логотип
Положите файл, например, в `app/static/img/logo.png`, и укажите путь в `logo:`
(относительно `app/static/`, без ведущего слэша). Используется и в шапке, и как
иконка вкладки.

### 3. `data/questions.json` — дерево вопросов
```json
{
  "start_node": "q1",
  "questions": {
    "q1": {
      "text": "Текст первого вопроса?",
      "answers": [
        { "text": "Да",  "next": "q2" },
        { "text": "Нет", "article": "result_a" }
      ]
    },
    "q2": {
      "text": "Текст второго вопроса?",
      "answers": [
        { "text": "Вариант", "article": "result_b" }
      ]
    }
  }
}
```
- `next` — переход к следующему вопросу (ключ из `questions`).
- `article` — финал: имя файла инструкции без `.md` (файл должен лежать в `articles/`).

### 4. `data/articles/*.md` — инструкции
Для каждого `article` из `questions.json` создайте файл `articles/<имя>.md`
с инструкцией в Markdown (поддерживаются списки, таблицы, жирный шрифт).

Заголовок карточки инструкции берётся из `article_titles` (по имени файла) либо из
общего `instruction_title` из `settings.yaml`.

### 5. `data/about.md` — страница «О проекте» (необязательно)
Опишите проект в Markdown. Если файл не создан — используется `about_text` из
`settings.yaml`.

## Запуск

### Локально (Python)
```bash
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
# Откройте http://localhost:8000
```

### В контейнере (podman/docker)
```bash
podman compose up -d --build   # сайт на http://<хост>:8080
```
